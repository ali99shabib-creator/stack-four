# Stack Four

A classic strategy board game based on smart moves, stacking, and different piece sizes.

## Game Features

Each player has 9 pieces:

- 3 Small pieces
- 3 Medium pieces
- 3 Large pieces

## Stacking Rules

- Medium pieces can cover Small pieces.
- Large pieces can cover Medium pieces.
- Large pieces can cover Small pieces.
- The goal is to line up four pieces.

## Game Modes

- Play vs AI
- Local Two Players
- Multiple difficulty levels

## Customization

Player 1 can change piece colors:

- Beige
- Dark Blue
- Gold
- Green

## Main Features

- 9 pieces per player
- 3 different piece sizes
- Strategic stacking gameplay
- Piece color customization
- AI opponent
- Local two-player mode
- Offline gameplay
- Arabic and English support
